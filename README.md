# Nina Carducci - Site portofolio photographe

Site vitrine pour Nina carducci, photographe indépendante basée à Bordeaux, réalisé dans le cadre du  Projet 4 de la Formation Développeur Web ( Openclassrooms)


Objectif du projet

Auditer et améliorer un site existant sur trois axes : performance, référencement, accessibilité, tout en corrigeant les bugs fonctionnels identifiés.

Performance

- Compression et optimisation des images (29Mo -> 1,2Mo)
- Images responsives ('srcset' / 'sizes')
- Attributs 'width' / 'height' pour eviter les décalages de mise en page (CLS)
- Chargement prioritaire de la premiére image du carroussel ( fetchpriority= hight)

Référencement (SEO)

- Balise <title> et méta-description optimisées
- Attribut lang=fr ajouté
- textes alternatifs (alt) sur toutes les images
- Balises open Graph et Twitter Cards pour le partage sur les réseaux sociaux
- Microdonnées Schema.org LocalBusines (référencement local, adresse, horaires)

Acessibilité

  - Labels de formulaire reliés à leurs champs (for/id)
  - Contraste des couleurs conforme (WCAG) sur le filtre de galerie sélectionné
  - Hiérarchie des tîtres
  - Balises sémantiques HTML5 (header, nav, main)
  - Libellés du carrousel traduits en francais car page fr
